# Changelog

## 0.1.0 — 2026-11-15

- Drag files out of the terminal, one row per file, with dragon-compatible flags
  (`-x`, `-a`, `-A`, `-t`, `-k`, `-p`, `-T`, `-i`, `-I`), plus `-N`.
- Drop target mode prints dropped file paths and URLs to stdout.
- The window floats above other windows by default, so it stays visible while you switch apps; `-N` turns this off.
